# 蓍草卜卦 — 周易大衍之數求卦系統

本專案依據《周易・繫辭上傳》所載「大衍之數」正統筮法，採用 **React 19 + Tailwind CSS + Framer Motion + Vite** 實作，呈現從「大衍之數五十，其用四十有九」到「十有八變而成卦」的互動卜卦與動畫推演過程。

---

## 🌟 功能亮點

1. **正統大衍筮法（十有八變）**：
   - 每爻歷經「分二、掛一、揲四、歸奇」三變而成（三變成一爻，六爻共十八變）。
   - 正確計算 9（老陽 / 太陽）、8（少陰）、7（少陽）、6（老陰 / 太陰）。
2. **生動動畫與互動體驗**：
   - 俯視桌上的一束蓍草，五十枝中自動虛一不用以象太極。
   - 用手指或滑鼠按住草束中的一處，向右撥開並放手，才會顯示左右兩堆枝數（分二以象兩儀）。輕點或拖回原位可以重新選擇。
   - 右堆抽出一枝上移（掛一以象三才）。
   - 四枝一組整齊成束，餘數高亮顯示（揲四以象四時）。
   - 掛一與餘數匯聚於扐（歸奇以象閏）。
3. **卦象與動爻標記**：
   - 每得一爻即由下至上實時更新卦象。
   - **老陽（太陽，9）**：爻位旁標示**紅色圓圈（○）**，陽變陰。
   - **老陰（太陰，6）**：爻位旁標示**綠色叉叉（✕）**，陰變陽。
   - 完成六爻後，若有動爻即於本卦右側展示**變卦（之卦）**；無動爻則標示無變卦。
4. **易經經文與解卦指南**：
   - 完整收錄 64 卦卦辭、384 條爻辭，以及乾卦「用九」、坤卦「用六」（通行本王弼/朱熹本繁體中文）。
   - 依朱熹《易學啟蒙》筮法準則，根據變爻數量（0 至 6 爻）提供主要參看的解卦指引。
   - 成卦結果及歷史紀錄詳情均可選擇「複製並開啟 ChatGPT」或「複製並開啟 Gemini」，在新分頁貼上這一卦的問題、卦象及參考經文後自行送出。
5. **速度控制與跳過功能**：
   - 支援 0.5x、1x、2x、4x 動畫播放速度。
   - 支援「跳過本變」與「快速完成」（以隨機切分快速算出結果）。
   - 「開始卜卦」按鈕隨時可重新點擊，立即重啟新的一局。
6. **本機紀錄儲存與調閱**：
   - 記錄所問之事、卜卦時間（開始與完成）。
   - 卜卦完成後自動儲存為 `records/` 目錄下的 `.json` 與排版精美的 `.md` 檔案。
   - 提供「歷史紀錄」抽屜，支援搜尋、閱讀詳細、下載 `.md` / `.json` 與刪除。

## 🚀 本機啟動與執行

### 使用 Docker Compose

啟動 Docker 後，在專案根目錄執行：

```bash
docker compose up -d --build --wait
```

開啟 [蓍草卜卦](http://127.0.0.1:5173/)。容器會以 Vite 預覽模式提供建置後的網頁與卜卦紀錄 API，預設僅供本機連線。若 5173 已被占用，可設定環境變數 `SHICAO_PORT` 後重新啟動，並使用對應連接埠開啟網頁。

卜卦紀錄的 JSON 與 Markdown 存在名為 `records` 的 Compose volume，掛載於容器的 `/app/records`。執行 `docker compose down` 可停止服務並保留紀錄，再次啟動即可調閱。

### 選用 Chrome 擴充功能，預填解卦草稿

1. 在桌面 Chrome 開啟 `chrome://extensions`，開啟「開發人員模式」。
2. 點「載入未封裝項目」，選擇專案中的 [chrome-extension](chrome-extension/) 資料夾（內含 `manifest.json`）。
3. 重新整理本機卜卦網站（`http://127.0.0.1` 或 `http://localhost`）。在成卦結果或歷史紀錄詳情按「預填並開啟 ChatGPT」或「預填並開啟 Gemini」。
4. 在新分頁確認或編輯草稿，再自行送出。若需登入，請在同一分頁完成登入。草稿可在五分鐘內領取。若輸入框已有文字或網站介面改版，可以回到卜卦分頁點「手動複製提示詞」。

擴充功能使用 Chrome 的工作階段儲存區，依新分頁編號暫存提示詞，領取或關閉分頁後清除。未安裝或停用時，網站沿用「複製並開啟」。更新擴充功能檔案後，請在擴充功能管理頁按「重新載入」，再重新整理卜卦網站。

### 1. 環境需求
- **Node.js** ≥ 18（建議 Node 20+）
- **npm** ≥ 9

### 2. 安裝相依套件
```bash
npm install
```

### 3. 本機開發啟動
```bash
npm run dev
```
啟動後於瀏覽器開啟 `http://localhost:5173` 即可開始卜卦。

### 4. 執行單元測試
```bash
npm test
```
包含大衍筮法算法、64 卦二進位對照、朱熹解卦規則、Markdown 輸出與儲存驗證。

### 5. 建置與正式預覽
```bash
npm run build
npm run preview
```

## 📜 筮法規則說明（《繫辭傳》）
- **大衍之數五十**：取五十枝蓍草。
- **其用四十有九**：留出一枝置於一旁以象太極，全程不參與推演。
- **分二以象兩儀**：使用者任意分開為左右兩堆，象天地陰陽。
- **掛一以象三才**：從右手堆抽出一枝夾置向上，象天、地、人三才。
- **揲四以象四時**：左堆與右堆分別每四枝一數，若整除則餘數算四（象春、夏、秋、冬四季）。
- **歸奇以象閏**：將掛一之枝與左右餘數合置於扐（第一變歸奇必為 5 或 9 枝；第二、三變歸奇必為 4 或 8 枝）。
- **三變成一爻**：三變之後剩餘蓍草數必為 36、32、28 或 24，除以四得：
  - **9**：老陽（太陽），爻象為陽，為動爻（變陰），標記 **紅色圓圈 ○**
  - **8**：少陰，爻象為陰，靜爻不變
  - **7**：少陽，爻象為陽，靜爻不變
  - **6**：老陰（太陰），爻象為陰，為動爻（變陽），標記 **綠色叉叉 ✕**
- **十有八變而成卦**：重覆六次得出初爻、二爻、三爻、四爻、五爻、上爻。
